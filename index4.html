03 / Case studies

Bugs worth writing up.

Four defects I found and root-caused, from an OAuth login loop to an onsite VR calibration fault - open each for the full report.

01 - AUTH

Login loop on backdated system clock

Changing the system clock to a past date made Keycloak report a successful login, then bounce the user back to the login screen in a loop.

Full report

Steps: Set the client's system date to the past → log in with valid credentials → submit.

Actual: UI shows a success toast, then redirects back to login instead of the dashboard - no way to proceed.

Root cause: Token issued-at/expiry checks are time-dependent; a backdated clock made the session token look invalid immediately after issuance.

KeycloakOAuthEdge case
02 - SECURITY

Sensitive data masked in UI, exposed in API response

An employee field shown masked on screen was returned fully unmasked in the raw API response.

Full report

Steps: Open a record with a masked sensitive field → inspect the network response for that endpoint.

Actual: The JSON payload contained the full, unmasked value - visible to anyone inspecting traffic.

Root cause: Masking was implemented client-side only; the backend never redacted the field before sending it.

SecurityAPI testingData exposure
03 - XR

VR rollercoaster drifted off-sync on a rightward glance

On a physical rollercoaster synced to VR headsets, looking right during one accelerating slope shifted the in-headset scene out of alignment with the real ride.

Full report

Investigation: Ruled out Wi-Fi and modem placement across 100+ onsite rides before isolating the trigger to one exact combination: that slope's acceleration point plus a rightward head turn.

Root cause: A build-level calibration issue in positional tracking during that acceleration/rotation combination - fixed by the dev team once reproduced with full conditions.

VR calibrationOnsite testingRoot-cause analysis
04 - BALANCE

Guided missiles got stuck at the map edge

Speed-boosting to the map boundary made incoming guided missiles freeze mid-air, letting the player dodge the hardest weapon in the game for free.

Full report

Steps: Draw a guided missile from an enemy drone → speed boost to the map edge before it connects.

Actual: The missile stops tracking and hangs in the air, letting the player safely close in and destroy the enemy drone with no risk.

Root cause: Missile tracking logic didn't handle the map-boundary condition, so it halted instead of continuing to track. Verified reproducible across multiple levels, including advanced-weapon stages.
